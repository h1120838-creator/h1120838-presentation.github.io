🌵 起源：拯救枯萎的生命

每次段考週一忙，家裡的盆栽就會因為忘記澆水而枯萎。這讓我思考：能不能利用課餘學到的程式設計與電子電路知識，做出一個能「自己照顧自己」的智慧系統？

實作歷程與技術拆解

第 1-2 週

🔌 硬體架構與電路連接

核心使用 Arduino Uno 開發板，連接土壤濕度感測器、抽水馬達（配合繼電器模組）以及 ESP8266 Wi-Fi 模組。最困難的是確認電壓供電，避免馬達啟動時造成開發板重啟。

第 3-4 週

💻 程式編寫與邏輯設定

我設定了一個濕度門檻值。當感測器回傳數值低於 30% 時，Arduino 會驅動馬達澆水 5 秒。同時，透過 ESP8266 將數據透過 MQTT 協定傳送至雲端。

// 核心邏輯範例
if (soilMoisture < 30) {
  digitalWrite(pumpPin, HIGH); // 啟動水泵
  delay(5000);                // 澆水5秒
  digitalWrite(pumpPin, LOW);  // 停止水泵
}
第 5-6 週

📱 遠端監控網頁開發 (Web/IoT)

這是最有趣的部分！我利用 HTML/CSS/JS 製作了一個前端面板，並透過 WebSocket 連接 MQTT 伺服器，實現即時數據更新。我還加了一個「手動澆水」按鈕，能從網頁發送指令給 Arduino。
